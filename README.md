# Petals & Meaning — Lily Apology Website

A cinematic, editorial-style apology experience built with Next.js, React, TypeScript, Framer Motion, and custom CSS.

## Features

- Animated opening with floating petals and a slowly moving floral photograph
- Scroll-based reveal animations
- Bouquet section focused on sincerity, care, and accountability
- Four lily cards: Casablanca, Stargazer, Tiger Lily, and Oriental Lily
- Responsive styling for phones, tablets, and desktop screens
- Reduced-motion support for visitors who prefer less animation

The apology letter and interactive ending have intentionally been left out.

## Run locally

Install Node.js 20.9 or newer, then in this folder run:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

To create a production build:

```bash
npm run build
npm start
```

## Images and fonts

Floral photographs are loaded from Unsplash image URLs, and fonts are loaded from Google Fonts. An internet connection is needed for those remote assets. The website itself does not require an API key.
